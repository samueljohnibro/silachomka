# 1. ECOSYSTEM OVERVIEW

## Chomka Nation

**Chomka Nation** is the wider ecosystem connecting the user's creative, technology, music, sports, and entrepreneurial work.

Current known ecosystem branches:

- **chomkaMUSIC™** — music/artist ecosystem and music studio.
- **chomkaTECH™** — technology/software/engineering ecosystem.
- **Spartamonuel** — sports/training brand created by the user and his brother, operating under Chomka Nation.
- **silachomka** — the user's artist/creator identity and public-facing media presence.
- **Silachomka Enterprise** — the broader media/creative/entrepreneurial operating layer this catalog supports.

The brands are **intertwined rather than isolated**. Content may intentionally move audiences between music, technology, sports, personal identity, products, websites, and other Chomka Nation initiatives.

# 3. OFFICIAL WEBSITE

## silachomka.com

**Website:** https://silachomka.com

The website is intended to function as the central owned-media hub for the silachomka identity.

### Known/current website sections

Based on the current website design/reference:

- Hero / artist introduction
- Explore Music
- Explore Beats
- Latest Release
- Music catalog
- Gallery / visual archive
- About / "More than the music"
- Chomka Nation ecosystem section
- Links to other Chomka Nation properties

### Website strategy

The website should be treated as the **owned-media source of truth**, while external platforms serve as distribution, discovery, streaming, purchasing, or community channels.

The website should eventually connect:

`silachomka → Music → Music Videos → Beats → Merch → Gallery → Chomka Nation`

and, where appropriate:

`silachomka → chomkaMUSIC → chomkaTECH → Spartamonuel → Chomka Nation`

### Beats page

The website is intended to contain a dedicated **Beats** page.

The beats may be displayed/catalogued on silachomka.com while purchases remain processed through **Selar**.

Expected flow:

`silachomka.com/beats → Beat/project page → Purchase → Selar checkout`

**Important:** The website should not replace Selar's transaction system unless that strategy is explicitly changed later.
