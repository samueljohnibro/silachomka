**Document Type:** Master Commercial Products & Media Assets Specification
**Status:** Living / Continuously Updated
**Authority:** Canonical reference for silachomka commercial products, beats, merchandise, media assets, purchase pathways, and related operational information
**Scope:** Beats, merchandise, digital products, music-video assets, media assets, commercial catalogue data, purchase/distribution pathways, and future monetizable creative assets

---

## 1. PURPOSE

This document is the commercial and operational inventory layer of the silachomka ecosystem.

Its purpose is to maintain a reliable representation of what can be sold, promoted, licensed, distributed, showcased, or otherwise used as a business/media asset.

The core model is:

**CONTENT → AUDIENCE → OWNED DESTINATION → PRODUCT / EXPERIENCE → TRANSACTION → LONG-TERM VALUE**

This file should answer practical questions such as:

- What products currently exist?
- What beats are available?
- What is each beat's canonical information?
- Where can a customer purchase it?
- What merchandise exists or is planned?
- What media assets support a release or campaign?
- Which assets are active, sold, unreleased, planned, archived, or unavailable?
- Which information is confirmed versus proposed?
- What commercial opportunities should be considered when new assets are created?

This document is intentionally operational. Brand identity belongs in `SILACHOMKA_BRAND_IDENTITY_AND_VOICE.md`; content execution belongs in `SILACHOMKA_CONTENT_AND_SOCIAL_PLAYBOOK.md`; detailed release/catalogue history belongs in `SILACHOMKA_MASTER_MEDIA_CATALOG.md`; ecosystem relationships belong in `CHOMKA_NATION_ECOSYSTEM_AND_BRAND_ARCHITECTURE.md`.

## 2. CORE COMMERCIAL PRINCIPLE

**Never invent a product, price, availability status, purchase link, or commercial claim.**

Every commercial reference should be traceable to:

1. confirmed project information;
2. an authoritative catalogue entry;
3. a user-provided update; or
4. an explicitly labelled future idea.

The system must distinguish:

- **Confirmed / Active**
- **Confirmed / Temporarily unavailable**
- **Sold / Completed**
- **Released / Catalogue asset**
- **Unreleased**
- **Planned**
- **Concept / Idea**
- **Archived**
- **Unknown / Needs confirmation**

If information is missing, mark it as unknown rather than guessing.

# 30. CREATOR STUDIO OPERATIONAL ARCHITECTURE (`/studio`)

The website includes an administrative creator system located at `/studio` for real-time media publishing and inventory management.

### 30.1 Access Mechanism
- **Access Route:** `silachomka.com/studio`
- **Access Gating:** Client-side passcode protection (`chomka2026`), global keyboard hotkey (`Ctrl + Shift + S` / `Cmd + Shift + S`), and secret gesture (triple-click footer copyright text).
- **Security Scope:** Documented accurately as client-side interface gating (not cryptographic remote server authentication).

### 30.2 Storage Engine & Persistence Lifecycle
- **Dual Persistence Architecture:** Synchronous in-memory cache (`memoryStore`) + browser **IndexedDB engine** (`silachomka_db`, object store `chomka_kv`) with automatic fallback.
- **Event Dispatch:** Dispatches `chomka_store_update` custom DOM events to trigger instantaneous reactive UI updates across all subscribed components without page reload.
- **Capacity & Media Handling:** IndexedDB provides high-capacity local browser storage for base64 photo/video media and multi-slide carousels (up to 20 media items per post).
- **Persistence Scope:** Data saved in the browser persists across page reloads, tab closures, and browser restarts. It is local to that client environment unless exported or baked into the canonical codebase.

### 30.3 Supported Inventory Operations
- **Gallery Publishing:** Mixed photo/video carousel builder (up to 20 items), drag-and-drop slide reordering, individual slide removal, category tagging.
- **Music Release Publishing:** Project title, edition numbering, tracklist creation with per-track platform streaming URLs.
- **Beat Catalogue Publishing:** Title, BPM, musical key, audio/video preview file binding, and three-tier Selar checkout links.
- **Video Visualizer Publishing:** YouTube embed parsing and category classification.
- **Management & Deletion:** Instant real-time deletion or modification of any existing or newly added item.
